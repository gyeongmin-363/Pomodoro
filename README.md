# 뽀모도로
- 디자인 : notion 스타일
- 미니멀 고양이 요소
- 추가해야하는 것 : 백색 소음 및 종료 음악 추가
- 삭제해야하는 것 : 배경 커스텀 -> (대신 투두리스트를 분리하거나, 백색 소음 설정 칸으로 변경)


요청하신 **"포모도로 + 같이 공부 + 플래너"** 기능을 결합하고, **Koyeb**과 **UptimeRobot**을 활용하여 서버를 유지하는 앱 기획서입니다.

---

## 1. 프로젝트 개요

- **앱 명칭:** **FocusConnect** (가칭)
- **핵심 가치:** "혼자 하는 공부에서 함께 하는 성취로"
- **주요 기능:** 포모도로 타이머, 실시간 공부방(공유 타이머), 데일리 플래너
- **디자인 컨셉:** **Notion 스타일** (미니멀, 모노톤 UI, 이모지 활용, 깔끔한 타이포그래피)

---

## 2. 주요 기능 상세

### 📅 플래너 (Planner)

- **할 일 관리:** Notion의 데이터베이스 리스트처럼 깔끔한 할 일 목록 작성.
- **우선순위 설정:** 중요도에 따른 태그 분류.
- **타이머 연동:** 플래너의 항목을 클릭하면 바로 해당 업무의 포모도로 타이머가 시작됨.

### ⏳ 포모도로 타이머 (Pomodoro)

- **커스텀 세션:** 25분 집중/5분 휴식 등 사용자 맞춤 설정.
- **시각적 피드백:** 공부 진행 상황을 Notion 스타일의 프로그레스 바(Progress Bar)로 표시.
- **통계:** 일일/주간 집중 시간 통계 대시보드.

### 🤝 같이 공부 (Shared Study)

- **실시간 상태 공유:** 현재 공부 중인 친구들의 목록과 집중 시간 실시간 표시.
- **공부방 생성:** 특정 주제나 시험을 목표로 하는 사람들과 함께 타이머 공유.
- **응원하기:** 이모지를 통해 실시간으로 친구에게 응원 보내기.

---

## 3. 기술 스택 및 아키텍처

| **구분** | **기술 스택** | **비고** |
| --- | --- | --- |
| **Frontend** | Android (Kotlin / Jetpack Compose) | 사용자 인터페이스 및 로직 |
| **Backend** | Node.js (Express) or Python (FastAPI) | 실시간 데이터 처리 및 API |
| **Database** | Supabase (PostgreSQL / Auth) | 사용자 정보 및 플래너 데이터 저장 |
| **Hosting** | **Koyeb** | 서버 배포 및 운영 |
| **Monitoring** | **UptimeRobot** | 서버 상시 가동 유지 (Free tier 슬립 방지) |

### 💡 인프라 운영 전략

- **Koyeb:** 도커 이미지 기반 배포를 통해 백엔드 서버를 구동합니다.
- **UptimeRobot:** Koyeb의 무료 티어는 일정 시간 요청이 없으면 휴면 상태가 될 수 있습니다. 5분마다 서버 URL로 HTTP Ping을 보내 **24시간 중단 없는 서버 상태**를 유지합니다.

---

## 4. UI/UX 디자인 가이드 (Notion Style)

- **색상:** 흰색 배경(`#FFFFFF`), 연한 회색 테두리(`#E9E9E7`), 검정색 텍스트(`#37352F`).
- **아이콘:** 기본 아이콘보다는 **Emoji**를 적극적으로 사용하여 Notion 특유의 감성 재현.
- **컴포넌트:** 둥근 모서리가 적은 카드 레이아웃, 심플한 텍스트 버튼.

---

## 5. 개발 로드맵

1. **1단계:** Jetpack Compose를 이용한 Notion 스타일의 UI 와이어프레임 구축.
2. **2단계:** 로컬 포모도로 타이머 및 플래너 기본 기능 구현.
3. **3단계:** Koyeb에 백엔드 서버 배포 및 Supabase 연동.
4. **4단계:** WebSockets 또는 Supabase Realtime을 활용한 '같이 공부' 실시간 기능 추가.
5. **5단계:** UptimeRobot 설정으로 서버 가동률 100% 확보 및 최종 테스트.
